# 💖 Happy 1st Anniversary

## หน้าต่างๆ
- `/anniversary/` — หน้าหลัก เลือกว่าจะดูวันครบรอบหรือวันเกิด (`src/home/`)
- `/anniversary/love/` — วันครบรอบ
- `/anniversary/birthday/` — วันเกิด

## เริ่มใช้งาน
```bash
npm install
npm run dev
```
แล้วเปิด http://localhost:5173

## ปรับแต่ง
- แก้ข้อความ ชื่อ วันที่เริ่มคบ และความทรงจำทั้งหมดได้ที่ `src/config.js`
- ใส่รูปไว้ที่ `public/photos/` แล้วใส่ path ใน `images` ของแต่ละ moment — ใส่กี่รูปก็ได้
  เช่น `images: ['/photos/1-1.jpg', '/photos/1-2.jpg']` (ค่าเริ่มต้นตั้งชื่อไว้เป็น `เลขmoment-เลขรูป.jpg`)
- ถ้ายังไม่มีรูป จะแสดงเป็นการ์ดสีพร้อม emoji แทน

## โหมดภาพยนตร์ 🎬
- กด "ดูแบบภาพยนตร์" ที่หน้าแรก → เล่นวนอัตโนมัติแบบวิดีโอแนวตั้ง 9:16
- กด "ดาวน์โหลดวิดีโอ" → อัดใหม่ตั้งแต่ต้น 1 รอบ แล้วดาวน์โหลดเป็น .mp4 (หรือ .webm แล้วแต่เบราว์เซอร์)
  ต้องเปิดหน้าค้างไว้จนอัดเสร็จ ห้ามสลับแท็บ
- ตั้งเวลาต่อรูป / ใส่เพลงประกอบได้ที่ `movie` ใน `src/config.js`

## หน้าวันเกิด 🎂 (`/birthday/`)
เปิดที่ http://localhost:5173/anniversary/birthday/ (บนเว็บจริงคือ `https://lexgamerdev.github.io/anniversary/birthday/`)
- แก้ชื่อ วันเกิด คำอวยพร รูป จดหมาย และคูปองได้ที่ `src/birthday/config.js` (ใส่ `{name}` `{age}` `{from}` ในข้อความได้)
- ลำดับฉาก: เปิดไฟในห้องมืด → เป่าเทียนบนเค้ก (แตะเทียน หรือเป่าใส่ไมค์จริง) → แตะลูกโป่งให้แตกเพื่ออ่านคำอวยพร → ปัดการ์ดโพลารอยด์ → เปิดจดหมายที่พิมพ์ทีละตัวอักษร → แตะกล่องของขวัญรัวๆ เพื่อเปิด พร้อมพลุและคูปอง
- โค้ดแยกอยู่ที่ `src/birthday/` ไม่ปนกับหน้าครบรอบ

## Build ไปใช้งานจริง
```bash
npm run build
```
จะได้ไฟล์ในโฟลเดอร์ `dist/` นำไป deploy ที่ Vercel / Netlify ได้เลย
